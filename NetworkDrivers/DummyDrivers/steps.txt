Assignment-3
The objective here is to simulate 2 network interfaces communicating with each other
1. Complete all the todos (1 to 24) in snull.c
2. Compile with make and this would generate snull.ko
3. Transfer & load snull.ko
4. Observe that it creates 2 interfaces - sn0 and sn1
5. Disable the ipv6 for sn0 and sn1 with
   $ sysctl -w net.ipv6.conf.sn0.disable_ipv6=1
   $ sysctl -w net.ipv6.conf.sn1.disable_ipv6=1
6. configure the following ip addresses
   $ ifconfig sn0 192.168.0.1 up
   $ ifconfig sn1 192.168.1.2 up
7. Ping 192.168.0.2 and it should succeed. Similarly, ping 192.168.1.1 and it should succeed
